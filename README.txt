GOLDEN GIRL — ANDROID SETUP

1. Extract this ZIP.
2. Host the folder on an HTTPS static host (for example GitHub Pages). A PWA needs HTTPS; opening index.html directly will not enable installation/offline features.
3. On your Android phone, open the hosted URL in Chrome.
4. Chrome menu ⋮ → Add to Home screen / Install app.
5. Open the app. Your tasks, goals, check-ins and ratings save in that browser on that device using local storage. Do not clear browser site data unless you have exported/backed up your data.

TIMED REMINDERS
- In Routines, set the daily and Sunday reminder times.
- Tap Export calendar.
- Open the downloaded golden-girl-reminders.ics file and import/add it to Google Calendar.
- Make sure Google Calendar notifications are enabled on Android.
- The app's own browser notification is best-effort while the app is open; Android/browser background limits mean it cannot guarantee alarms when closed. Google Calendar is the dependable reminder route.

PRIVACY
All planner data is stored locally in your browser. This starter app does not send your entries to a server.
